# Translation glossary

Terms that must stay consistent across the interface. When a language is added, add its column here first.

| English        | Persian (fa)    | Notes                                                   |
| -------------- | --------------- | ------------------------------------------------------- |
| Production     | تولید           | A film, event or shoot as a whole project               |
| Shoot day      | روز فیلم‌برداری | One working day of a production                         |
| Schedule block | بلوک برنامه     | A scene or activity with a start and end time           |
| Call time      | ساعت حضور       | When a person must arrive; never "تماس"                 |
| Crew           | عوامل           | The people working on a production                      |
| Equipment      | تجهیزات         |                                                         |
| Location       | لوکیشن          | Transliterated, as is standard on set                   |
| Conflict       | هم‌پوشانی       | Used for double-booking of a person or an item          |
| Acknowledge    | تأیید دریافت    | A crew member confirming they have seen their call time |
| Department     | بخش             | Camera, sound, art and so on                            |
| Producer       | تهیه‌کننده      |                                                         |
| Owner          | مالک            |                                                         |
| Viewer         | مشاهده‌گر       |                                                         |

The brand name Callboard is never translated or transliterated.
